### 🛠️ Building Agents — My Approach

- **Spec-first** — define the agent's goal, tools, and constraints before coding
- **Tool-calling as the unit of agent capability** — each tool is a clear, testable interface
- **Orchestration with LangGraph / CrewAI** for multi-agent workflows
- **Grounding agents with RAG and structured outputs** for reliable, factual responses
- **Wrapping agents in CLIs, APIs, or ComfyUI nodes** for real-world usage
